Bu proje, Java programlama dili kullanılarak geliştirilmiş, ağ tabanlı, iki oyunculu bir Amiral Battı (Battleship) oyunudur. Amiral Battı, oyuncuların sıralı hamlelerle birbirlerinin gemilerini bulup batırmaya çalıştığı klasik bir strateji oyunudur. Bu uygulama, socket programlama kullanılarak oluşturulan bir istemci-sunucu (Client-Server) mimarisi üzerine kurulmuştur. İstemciler, projede belirtilen (örneğin, bir Amazon Web Services - AWS EC2 veya yerel) sunucuda çalışan ortak bir sunucu uygulamasına bağlanarak etkileşim kurarlar. Oyuncular, oyun süresince gemi yerleştirme, rakip alana atış yapma, isabet, ıskalama ve gemi batırma gibi durumları gerçek zamanlı olarak deneyimleyebilmektedirler.
